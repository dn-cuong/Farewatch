# FareWatch frontend (React + TypeScript + Vite)

See the repository root [README.md](../README.md) for architecture, env vars, and how to run the full stack.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Set `VITE_API_URL` to the GraphQL endpoint (default `http://localhost:8080/graphql`).
